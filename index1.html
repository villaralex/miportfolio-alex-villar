Bienvenido a mi rincón de programación

Este blog nace mientras curso el Curso Introductorio de Frontend en Plataforma 5. Acá voy a ir compartiendo lo que aprendo, mis dudas y algunos tips que me van sirviendo en el camino.
Todavía estoy dando mis primeros pasos, así que este espacio va a ir creciendo a medida que avanzo en el curso.

La idea es que sirva tanto de repaso para mí como de guía para cualquiera que esté arrancando en el mundo del desarrollo web.

  1. Visual Studio Code como editor de código
  2. Git y GitHub para guardar y versionar mis proyectos
  3. La terminal (bash) para moverme entre carpetas y ejecutar comandos
